# Копилка Pro

Премиальное приложение-копилка на чистом HTML, CSS и JavaScript. Без сборки, регистрации и сервера: откройте `index.html` двойным кликом — и всё работает.

## Запуск

1. Скачайте папку проекта.
2. Откройте `index.html` в браузере (Chrome, Safari, Edge, Firefox).
3. Для установки как PWA и офлайн-режима разместите папку на GitHub Pages или любом статическом хостинге и откройте по HTTPS.

Никаких `npm install`, сборщиков и ES-модулей. Все скрипты подключены обычными тегами `<script>` в нужном порядке, общий неймспейс — `window.KP`.

## Что реализовано (этап 1)

- Онбординг: имя, валюта, первая цель, стартовая сумма; демо-режим.
- Главная: общий баланс с маскировкой сумм, изменение за месяц, спарклайн, быстрые действия, карусель целей, стрик, последние операции.
- Цели: создание, редактирование, удаление с отменой, закрепление, архив, эмодзи и градиентные обложки, дедлайн, приоритет, заметка и ссылка.
- Экран цели: большая карточка, кольцо прогресса, накоплено/осталось/процент, средняя скорость, прогноз, сумма до дедлайна, график, лента операций.
- Операции: пополнение, снятие, перевод между целями, цифровая клавиатура, категории (включая свои), теги, комментарий, дата и время, редактирование, дублирование, удаление с отменой.
- История: группировка по дням с итогом за день, поиск, фильтр по типу, «показать ещё».
- Аналитика: баланс, пополнения и снятия по месяцам, категории трат, сравнение целей, норма сбережений, текстовый инсайт.
- Настройки: тема (тёмная, светлая, AMOLED), 6 акцентов, валюта, формат даты, скрытие сумм, демо-данные, экспорт/импорт JSON, сброс.
- Данные: `localStorage`, ключи с префиксом `kopilka_`, `schemaVersion` и миграции, суммы в копейках, мягкое удаление, резервная копия, восстановление после повреждения.
- PWA: `manifest.json`, service worker, офлайн-кэш, иконка.
- Доступность: aria-атрибуты, фокус, клавиатура, `prefers-reduced-motion`.

## Проверка

В консоли браузера выполните:

```js
KP.selfTest()
```

Проверяются перевод денег в копейки, форматирование, балансы, переводы, миграция `v1 → v3`, прогноз и проценты.

## Данные

Всё хранится в одном объекте `localStorage` под ключом `kopilka_state`. Повреждённые данные не перезаписываются: при запуске приложение предложит скачать их, восстановить резервную копию или начать заново.

## Лицензия

Учебный проект. Название, иконка и оформление «Копилка Pro» созданы специально для этого приложения и не используют ассеты реальных банков.
