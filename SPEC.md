# SPEC

## 1. Рамки и техника
- Ты можешь только создавать и править файлы в папке проекта. Не запускай команды, не используй git, npm, сборщики.
- Только HTML, CSS, чистый JavaScript. Обычные <script> в порядке зависимостей, НЕ ES-модули (сайт должен открываться двойным кликом по index.html). Общий неймспейс window.KP.
- Структура: index.html, manifest.json, sw.js, icon.svg, README.md, css/ (tokens.css, base.css, components.css, screens.css), js/ (utils.js, store.js, ui.js, charts.js, router.js, app.js, screens/*.js). Каждый файл не длиннее ~400 строк, при росте дроби.
- Все пути относительные (./css/..., ./js/...), никаких путей с «/» в начале: сайт будет на GitHub Pages по адресу ник.github.io/репозиторий/.
- Внешне разрешён только Chart.js через CDN (фиксированная версия). Остальное (heatmap, кольца, спарклайны, конфетти) рисуй сам на SVG/canvas.
- Не используй название, логотип и фирменные ассеты реальных банков. Название: «Копилка Pro», иконку нарисуй сам.
- Весь интерфейс на русском. Комментарии в коде на русском.
- Код полностью, без заглушек и сокращений.

## 2. Дизайн-система (стиль топового банковского приложения)
- Токены в CSS-переменных. Тёмная тема по умолчанию (фон ~#0F0F10, карточки #1B1B1D / #232326, границы rgba(255,255,255,.06)), светлая тема и AMOLED-тема. Акцент по умолчанию жёлтый #FFDD2D (текст на нём тёмный), ещё 5 акцентов на выбор.
- Типографика: системный шрифт, шкала 12/14/16/20/28/40/56, tabular-nums для сумм, большие заголовки экранов, сворачивающиеся в компактную шапку при скролле.
- Радиусы 12/16/24/32, сетка отступов 4/8/12/16/24, мягкие тени, glass-эффект (backdrop-filter) на нижней панели и шапках.
- Анимации 150–400 мс, easing cubic-bezier(.2,.8,.2,1): появление карточек каскадом, count-up суммы, заполнение прогресса, пружинные bottom-sheet, scale при нажатии (0.97), skeleton-загрузка, ripple. Учитывай prefers-reduced-motion.
- Компоненты: bottom-sheet, модалка, snackbar с кнопкой «Отменить», чипы, сегментированный переключатель, toggle, табы, карточки целей как банковские карты (градиент, эмодзи, мини-спарклайн), кольцевой прогресс, экранная цифровая клавиатура для ввода суммы как в банке, swipe-действия на операциях (влево удалить, вправо изменить), пустые состояния с SVG-иллюстрациями, вибро-отклик через navigator.vibrate.
- Mobile-first (360–430px), на ПК контент колонкой ~480px по центру, viewport-fit=cover и safe-area-inset для нижней панели.
- Нижняя панель: Главная, Цели, История, Аналитика, Ещё. Навигация через hash-роутер (#/home, #/goals, #/goal/ID ...), кнопка «назад» браузера работает.

## 3. Функции
A. Онбординг и «сториз»: при первом запуске мастер (имя, валюта, первая цель, стартовая сумма). Сверху главной полоска «сториз» с инсайтами (итог недели, стрик, совет, близость цели) в полноэкранном просмотре с автопереключением.
B. Главная: общий баланс с «глазом» (скрыть суммы), изменение за месяц, карусель карточек целей, быстрые действия (Пополнить, Снять, Перевод между целями, Челлендж), ожидающие автопополнения, последние операции, виджет стрика.
C. Цели: создание/правка/удаление, эмодзи и градиент-обложка, приоритет, закрепление, drag-and-drop порядок, дедлайн, этапы-вехи с галочками и конфетти, заморозка, архив, «Куплено!» (завершить цель с итоговой статистикой), вишлист-поля (цена, ссылка, заметка), перевод денег между целями.
D. Экран цели: большая карточка, кольцо, накоплено/осталось/процент, средняя скорость в неделю и месяц, прогноз даты достижения, «сколько откладывать в неделю/месяц до дедлайна», график цели, вехи, лента операций цели.
E. Операции: пополнение, снятие, перевод. Ввод через цифровую клавиатуру. Категории с иконками (+ свои), теги, комментарий, дата и время, редактирование, дублирование, удаление с отменой, массовый выбор. При снятии обязательно «на что потрачено».
F. Автопополнения: правило «каждую неделю/месяц N на цель». В фоне ничего не работает, поэтому при открытии приложение считает пропущенные и показывает «ожидают подтверждения» с подтверждением в один тап.
G. Челленджи: «52 недели», «100 конвертов», «день без трат», «округление покупок» (вводишь покупку, копится разница до 10/50/100). Прогресс, награды.
H. Достижения (бейджи), стрик, конфетти и поздравления на важных событиях.
I. История: группировка по датам с итогом за день, фильтры (цель, тип, категория, период, теги), поиск, сортировка, экспорт CSV.
J. Аналитика: динамика баланса (неделя/месяц/год/всё), пополнения vs снятия по месяцам, кольцо категорий трат, календарь-heatmap пополнений как у GitHub, активность по дням недели, сравнение целей, норма сбережений, лучший и худший месяц, прогноз со сценариями (ползунок «если откладывать X в неделю»), калькулятор процентов (простая и сложная капитализация), автоматические текстовые инсайты.
K. Лимиты на снятия по категориям с предупреждениями.
L. Поделиться: генерация картинки-карточки прогресса цели через canvas (скачать PNG).
M. Настройки: тема, акцент, валюта, формат даты, PIN-код (хэш SHA-256 через WebCrypto, автоблокировка), скрытие сумм, экспорт/импорт JSON, CSV, демо-данные, сброс с подтверждением, напоминание о бэкапе раз в 14 дней, о приложении.
N. PWA: manifest, service worker с кэшем, офлайн-режим, подсказка «Установить».

## 4. Данные
- Один объект в localStorage, ключи с префиксом "kopilka_", поле schemaVersion и функция миграций.
- Суммы хранить целыми в минимальных единицах (копейки), даты в ISO, id через crypto.randomUUID.
- Мягкое удаление для отмены, store с подпиской на изменения, сохранение с debounce, всё чтение/запись в try/catch. Повреждённые данные не затирать, а предлагать восстановление.
- При старте вызвать navigator.storage.persist().
- Импорт JSON с проверкой структуры и версии и подтверждением.

## 5. Качество
- Доступность: aria-атрибуты, фокус, контраст, управление с клавиатуры.
- Безопасность: пользовательский текст только через textContent или экранирование.
- Производительность: делегирование событий, без утечек, плавные 60 fps.
- Функция KP.selfTest() в консоли, проверяющая расчёты денег, прогнозов и миграции.
